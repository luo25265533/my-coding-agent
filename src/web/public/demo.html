my-coding-agent Demo Page

这是一个静态演示页面，位于 src/web/public/demo.html， 可以直接在浏览器中打开，也可以通过 web server 静态访问。

页面包含完整的 HTML5 结构、UTF-8 字符编码声明，以及少量内联 CSS 样式，用于验证静态资源的构建与复制流程。

HTML5 结构

标准 doctype 与语义化标签，浏览器可直接打开。

UTF-8 编码

显式声明字符编码，中英文混排无乱码。

构建复制

copy-public.js 会随构建拷贝静态资源到产物目录。
